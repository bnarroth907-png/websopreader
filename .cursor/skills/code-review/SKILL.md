# 企業內部系統程式碼審查

## 審查重點（依序檢查）

### 安全性
- 是否有權限與資料範圍校驗
- 敏感資料是否可能外洩
- 是否有 SQL 注入、XSS、CSRF 風險

### 規範符合度
- 是否遵循專案目錄結構與命名
- 是否使用統一的 API 封裝與錯誤處理
- UI 是否使用設計系統組件

### 可維護性
- 邏輯是否過於複雜
- 是否有重複程式碼可抽取
- 型別是否完整

### 可觀測性
- 關鍵操作是否有日誌
- 錯誤是否有足夠上下文（traceId）

## 輸出格式
以表格或清單列出：
- 嚴重問題（必須修）
- 建議改進
- 做得好的地方
