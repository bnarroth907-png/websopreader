# 開發新功能標準流程

## 步驟
1. **釐清需求**
   - 確認功能範圍、權限要求、是否涉及敏感資料
   - 如有不清楚的地方，先問使用者

2. **查看現有實作**
   - 搜尋類似功能的頁面與 API
   - 確認是否已有可複用的組件、hook、服務

3. **規劃變更**
   - 列出需要修改 / 新增的檔案
   - 標註前端與後端各自負責的部分

4. **實作**
   - 前端：頁面 + 組件 + API 呼叫 + 權限控制
   - 後端：API + 權限校驗 + 資料範圍限制 + 操作日誌
   - 遵循專案現有目錄結構與命名

5. **自檢清單**
   - [ ] 有 loading / empty / error 狀態
   - [ ] 權限控制正確（前端 + 後端）
   - [ ] 敏感資料未外洩
   - [ ] 錯誤處理完整
   - [ ] 有基本的型別定義

6. **建議測試點**
   - 正常流程
   - 無權限情況
   - 邊界資料
   - 錯誤回應
