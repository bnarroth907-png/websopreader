# Document Control Procedure

**Document ID:** SOP-QA-004  
**Version:** 2.0  
**Effective Date:** 2026-02-01  
**Owner:** Quality Assurance

## Purpose
To control the creation, revision, distribution, and obsolescence of quality documents.

## Procedure

### 1. Document Creation
1. Author prepares draft using approved template
2. Assign unique document number
3. Submit for review

### 2. Review and Approval
1. Subject matter experts review content
2. Quality reviews for compliance
3. Approver signs off
4. Document becomes effective

### 3. Distribution
1. Controlled copies distributed to relevant personnel
2. Uncontrolled copies marked as such
3. Electronic versions stored in document management system

### 4. Revision
1. Initiate change request
2. Update version number
3. Follow approval process
4. Obsolete previous version

## Retention
- Current versions: indefinite
- Obsolete versions: 5 years or as required by regulations
